 # PadelBook — הצעת פרויקט

מערכת מקומית ב־Python לניהול הזמנות, רשימת המתנה ותקלות במועדון פאדל.

## הצורך העסקי

ניהול ידני עלול לגרום להזמנות חופפות, טעויות בתמחור ואובדן הזדמנויות למלא שעות שהתפנו בעקבות ביטולים. כמו כן, יש למנוע הזמנות במגרשים מושבתים ולתעדף טיפול בתקלות.

## משתמשים ותפקידים

- **עובד/ת קבלה:** הזנת לקוחות ובקשות, אישור הזמנות, טיפול בביטולים ובקשות המתנה.
- **מנהל/ת המועדון:** הגדרת מגרשים ותעריפים, דיווח ועדכון תקלות, ובחינת תפוסה.
- **לקוחות:** בקשות להזמנה או לביטול באמצעות הקבלה.

## תהליכים מרכזיים

### הזמנה

המערכת בודקת את תקינות הבקשה, את כשירות המגרש ואת זמינותו למשך המשחק כולו. אם התנאים מתקיימים, היא מחשבת את המחיר ויוצרת הזמנה מאושרת. אחרת, ניתן להוסיף את הבקשה לרשימת ההמתנה למועד המבוקש.

### ביטול ורשימת המתנה

ביטול מפנה את המועד. המערכת מאתרת את הבקשה המתאימה הראשונה לפי סדר ההצטרפות ומעבירה אותה לקבלה לתיאום ולאישור. בקשות שאינן מתאימות נשארות במקומן המקורי ברשימה.

### תקלות ותחזוקה

התקלות מתועדפות לפי דחיפות: מפגע בטיחות, פגיעה במשחק, ולבסוף תקלה קוסמטית. בשוויון נשמר סדר הדיווח. תקלה משביתה חוסמת הזמנות חדשות ומסמנת הזמנות קיימות לבדיקה. עם סגירתה, המגרש חוזר לפעילות רק אם אין בו תקלה משביתה פתוחה אחרת.

## זרימת מידע ותוצרים

המנהל/ת מזין/ה מגרשים, תעריפים ותקלות; הקבלה מזינה לקוחות, מועדי משחק וביטולים. המערכת מעדכנת הזמנות, רשימת המתנה וכשירות מגרשים, ומפיקה מחיר, אישור, מידע על זמינות, סיכום תפוסה ורשימת התקלה הבאה לטיפול. נתוני ההדגמה יהיו סינתטיים בלבד.

## ישויות וקשרים

- **מועדון:** מכיל מגרשים ומרכז את ההזמנות, רשימת ההמתנה והתקלות.
- **מגרש:** בעל מזהה, סוג (פתוח או מקורה) ותעריף. לכל סוג מדיניות ביטול משלו; למגרש פתוח ניתן יהיה להוסיף בהמשך התחשבות במזג האוויר.
- **הזמנה:** מקשרת לקוח ולמגרש וכוללת מועד התחלה, משך, מחיר ומצב.
- **בקשת המתנה:** מקשרת לקוח, מגרש ומועד מבוקש.
- **תקלת תחזוקה:** משויכת למגרש וכוללת דחיפות, סדר דיווח, מצב טיפול והאם היא משביתה את המגרש.

## תרחישי שימוש

1. **הזמנת משחק של 90 דקות:** ההזמנה מאושרת רק אם המגרש כשיר וכל פרק הזמן פנוי; המחיר מחושב בהתאם לתעריף.
2. **ביטול ואיוש מחדש:** לאחר ביטול, המערכת מאתרת את בקשת ההמתנה המתאימה הראשונה ומאפשרת לקבלה לאשר הזמנה חלופית ללא חפיפה.

## ערך עסקי

מניעת חפיפות וטעויות מחיר, טיפול מהיר והוגן בבקשות, ניצול טוב יותר של שעות שהתפנו ותעדוף מפגעים הפוגעים בבטיחות או בפעילות המועדון.

## הרחבות עתידיות

תחזית גשם ורוח משירות חיצוני תסייע לזהות הזמנות בסיכון במגרשים פתוחים ולהציע מגרש מקורה פנוי. אם המידע אינו זמין או אינו תקין, ההזמנה תישמר ותסומן לבדיקה ידנית.
